# Lib

Shared non-UI code: theme, storage (`storage.ts` with the `upgradeRecord` migration hook, `storageKeys.ts`), a small external store (`store.ts`), focus trapping, token reading, money (`money.ts`, integer pence, with `ExactPence` for exact fractions of a penny before the one rounding at output, `wholeSteps` for counting whole steps of an exact amount, and `FinePence` and `Factor`, fixed point for compound growth whose factors can be irrational, with the car finance rate solver's tolerance and step bound, the APR display digits and the flip-point search constants), the calendar divisors (`periods.ts`: months and weeks for per-period views, the default weeks of Child Benefit, and `PERIODS_PER_YEAR` for compounding and contribution frequencies), the optimiser's default sweep step and point limit (`sweep.ts`, display choices, not tax figures), bounds on what an input accepts (`inputLimits.ts`: amounts, children, items per list, name length, the largest percentage, the longest tax code text and the largest code number, the compound interest horizon cap, rate bounds and starting years, the car finance term, rate, mileage and excess-per-mile bounds, the car ownership bounds, the car decision page's starting horizon and its sensitivity shifts, the longest mortgage term; not tax figures), the shared schedule helpers for a loan repaid monthly (`amortising.ts`: `monthlyFactor`, `monthlyRate`, `interestOn`, `regularPayment`, `annualRate`, moved from car finance in M1, MO15), a pure calendar (`calendar.ts`: leap years, days in a month and a year, payment dates a whole number of months on, days between dates and by calendar year; no clock), verified unit conversions (`units.ts`: litres per gallon), display formatting (`format.ts`, with `formatPence` for a cost per mile) and ISO dates (`isoDate.ts`). See `docs/money.md`. Also: input parsing (`parse.ts`, with `parseDecimalText` and `decimalRatio` for plain decimals such as miles per gallon), untrusted-JSON checks (`validate.ts`) and file download and reading (`download.ts`). Scenarios live in `src/scenarios/`.
