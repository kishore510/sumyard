# Lib

Shared non-UI code: theme, storage (`storage.ts` with the `upgradeRecord` migration hook, `storageKeys.ts`), a small external store (`store.ts`), focus trapping, token reading, money (`money.ts`, integer pence, with `ExactPence` for exact fractions of a penny before the one rounding at output, and `wholeSteps` for counting whole steps of an exact amount), the month and week divisors for per-period views and the default weeks of Child Benefit (`periods.ts`), the optimiser's default sweep step and point limit (`sweep.ts`, display choices, not tax figures), bounds on what an input accepts (`inputLimits.ts`: amounts, children, items per list, name length, the largest percentage; not tax figures), display formatting (`format.ts`) and ISO dates (`isoDate.ts`). See `docs/money.md`. Also: input parsing (`parse.ts`), untrusted-JSON checks (`validate.ts`) and file download and reading (`download.ts`). Scenarios live in `src/scenarios/`.
