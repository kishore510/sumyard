**Sumyard has no tax figures yet.** None of this is in use until the first calculator arrives.

## Where figures will come from

- Each tax year’s rules will live in one place in Sumyard, checked against official sources such as GOV.UK and HMRC.
- Every figure will record where it came from and the date it was checked.
- A figure that has not been checked will stop any calculator that needs it from showing a result, rather than guess.

## The “last verified” label (coming)

Each calculator will show which tax year it uses and when its figures were last checked. If a Budget changes the rules, the label tells you whether Sumyard has caught up.

## The region setting

Settings has a default **Region**. Calculators will start with it, and you will be able to change it in each one. Nothing uses it yet.

> Sumyard’s results will be illustrative estimates, not financial advice. Check anything important against an official source.
