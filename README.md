# Sumyard

Personal UK finance calculators in one clean, ad-free web app. Static, client-side only, hosted on GitHub Pages. Illustrative, not financial advice.

- `npm ci`, then `npm run dev`. Before committing: `npm run lint`, `npm run typecheck`, `npm test`; `npm run build` also scans the output for external URLs.
- Rules: `CLAUDE.md`. Current work: `PHASE-BRIEF.md`. Roadmap: `PLAN.md`. Changes: `CHANGELOG.md`.
